# Recreto — No-Prompt AI Photo Studio

> "Upload one selfie. No prompts, no setup, no thinking. Your face stays yours — studio-clean portraits, passport and ID photos, all done in a minute."

**Website:** https://recreto.com

Recreto ("Recreate" + "Photo") turns one ordinary selfie into professional photos with AI. There are no prompts to write and no settings to tweak.

## Features

- **Studio portraits:** professional headshots from a single selfie, ready for LinkedIn, resumes, and Slack profiles
- **Passport and ID photos:** generated from the same selfie, with no photographer or studio needed
- **About a minute per result:** upload, let the AI pick the style, framing, and retouching, then download
- **Credit packs, no subscriptions:** 1 credit = 1 AI photo; one-time purchases that don't expire
  - Starter: 20 credits, $9.99
  - Pro: 60 credits, $19.99
  - Studio: 150 credits, $39.99
- **Privacy:** photos are never used for AI training, and storage is encrypted

See https://recreto.com/pricing for current pricing.
